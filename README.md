# 🤖 通义万相视频生成

> ✨ 通过 AI，将你的奇思妙想，一键化为生动视频！

本插件基于 [阿里云通义万相](https://www.tongyi.com/) 服务，赋予了 NekroAgent 使用文字生成视频的能力。它采用异步非阻塞设计，确保在生成视频时不会影响其他任务的执行，并内置了管理员审批流程，有效控制 API 资源消耗。

## 🚀 功能特色

- **文生视频**：通过与 AI 对话，描述你想要的画面，即可创作出视频。
- **异步处理**：视频生成任务在后台运行，不影响 Agent 的正常响应。
- **管理员审批**：可配置的审批流程，管理员可以审核、批准或拒绝视频生成请求。
- **任务管理**：提供完整的指令集，方便管理员查看任务列表、查询任务详情。
- **历史记录**：自动记录生成历史 (面向 AI)，方便回顾和再次使用。

## 📖 如何使用

### 生成视频

直接向 AI 发出请求即可，请尽可能详细地描述你的需求，包括**场景、角色、动作、画风**等，这样 AI 能更好地理解你的意图。

**例如：**

> “帮我生成一个视频，内容是：一只可爱的蓝眼睛小猫，在明亮的满月下飞快奔跑，周围是安静的森林，树叶在空中飞舞，希望能有动态镜头感。”

AI 在接收到任务后，会创建视频生成任务。如果开启了管理员审批，任务需要等待管理员批准后才会开始执行。

### 管理员指令

管理员可以通过以下指令来管理视频生成任务：

- `/wanx_y [任务ID]`

  - **功能**：批准一个待处理的视频生成任务。
  - **用法**：如果只有一个任务待处理，可省略 `[任务ID]`。

- `/wanx_n [任务ID]`

  - **功能**：拒绝一个待处理的视频生成任务。
  - **用法**：如果只有一个任务待处理，可省略 `[任务ID]`。

- `/wanx_list [页数]`

  - **功能**：查看视频生成任务列表。
  - **用法**：可指定页数，默认为第 1 页。

- `/wanx_info <任务ID>`
  - **功能**：查询指定任务的详细信息。
  - **用法**：必须提供 `任务ID`。

## ⚙️ 插件配置

你可以在插件配置页面找到本插件的设置选项：

| 配置项                 | 默认值                                  | 说明                                                                                                                      |
| :--------------------- | :-------------------------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| **阿里云百炼 API Key** | -                                       | 用于请求通义万相服务的凭证，可在 [阿里云百炼控制台](https://bailian.console.aliyun.com/console?tab=model#/api-key) 获取。 |
| **管理频道**           | -                                       | 用于接收和处理视频生成审批请求的频道。如果留空，将在当前发起请求的频道进行审批。                                          |
| **是否需要管理员审批** | `是`                                    | 控制是否所有视频生成请求都必须经过管理员批准。关闭后，请求将直接执行，可能导致 API 额度消耗剧增，请谨慎操作。             |
| **API 基础 URL**       | `https://dashscope.aliyuncs.com/api/v1` | 阿里云服务 API 的地址，通常无需修改。                                                                                     |
| **视频生成模型**       | `wanx2.1-t2v-turbo`                     | 可选项：`wanx2.1-t2v-turbo` (高性价比/快速) 或 `wanx2.1-t2v-plus` (高质量/慢速)。                                         |
| **轮询间隔**           | `10`                                    | 查询任务状态的时间间隔（秒）。                                                                                            |
| **最大轮询次数**       | `120`                                   | 单个任务状态查询的最大次数，用于防止无限等待。默认总时长约为 20 分钟。                                                    |
| **最大历史记录**       | `99`                                    | 每个会话（如群聊、私聊）保留的最大历史记录条数。                                                                          |
| **显示历史数量**       | `3`                                     | 在 AI 的思考背景中注入最近几次的历史记录数量，帮助 AI 更好地利用已经生成的资源。                                          |
| **每页显示任务数**     | `5`                                     | 使用 `/wanx_list` 指令时，每页展示的任务数量。                                                                            |
